# Feature guide — account opening POC (Stanbic IBTC and FirstBank)

Static site: `index.html` (overview), `brd.html` (Bulk Account Opening BRD coverage) and one page per persona,
generated by `build.py` from `content.py` and `brd.py`. Served by the app at `/guide/index.html`
(dev: http://localhost:5180/guide/index.html) and linked from the launcher (`src/skeleton/index.tsx`).

    python3 public/guide/build.py        # Python 3.12+; rebuild after editing content.py or brd.py

Screenshots: `shots/<id>.jpg`, taken with `capture/` (see capture/README.md). Built from the feature guide kit
(`../feature-guide-kit`); `build.py`, `guide.css` and `guide.js` are the kit's engine, unchanged.

## Two banks

`build.py` writes the Stanbic IBTC guide to `guide/` and the FirstBank guide to `guide/firstbank/` (with its own
`shots/`, logo and favicon). Each page checks the theme the admin dashboard has active (the saved profile in
`zara_local_profiles_v1`, the same one the apps load) and moves to the matching bank's copy, so
`/guide/index.html` always shows the bank on screen. `?bank=stanbic` or `?bank=firstbank` forces one.
In `content.py`, write `{BANK}` for the bank's name, never a bank's name.

Screenshots per bank: `capture/_assemble.sh` writes `shoot-<persona>.js` (Stanbic) and
`shoot-<persona>.firstbank.js` (seeds the FirstBank theme from `capture/firstbank-theme.json`, the published
AuraConfig "FirstBank" v4, and uploads from `fixtures-firstbank/`). Then `./to-jpeg.sh firstbank`.
A step with no shot for its bank renders as text only; it never borrows the other bank's screenshot.
